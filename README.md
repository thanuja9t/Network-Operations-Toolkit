# Network Operations & IT Helpdesk Toolkit

A collection of Python automation scripts designed to simulate **Network Monitoring**, **Incident Management**, and **SLA Ticket Tracking** for entry-level IT operations roles.

## Projects Included

### 1. Python Network Uptime Monitor & Logger (`network_monitor.py`)
* **What it does:** Continuously pings target servers or IP addresses, tracking uptime and downtime status changes in real time.
* **Incident Tracking:** Automatically logs network outages and recovery timestamps into an `incident_log.csv` file.
* **Tech Stack:** Python (`subprocess`, `csv`, `datetime`, `platform`).

### 2. Mini IT Helpdesk & SLA Tracker (`helpdesk_tracker.py`)
* **What it does:** Uses Object-Oriented Programming (OOP) to create, manage, and update support tickets categorized by network, hardware, or software issues.
* **SLA Monitoring:** Tracks ticket priority levels, live durations, and resolution times to simulate service-level agreement compliance.
* **Tech Stack:** Python (`datetime`, OOP principles).

## How to Run
You can run these scripts directly in any Python environment or execute them interactively via **Google Colab**.
